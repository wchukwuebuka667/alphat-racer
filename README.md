# ALPHAT RACER
Lane-dodging racer. Wallet is optional: holders of the token get a gold car and one shield.
Robinhood Chain Testnet (46630). Read-only chain access, no private keys.

    npm install
    cp .env.example .env
    npm run dev

After launching the token on vibe/vibe, set VITE_ALPHAT_TOKEN (locally and in Vercel), then redeploy.
Balance checks can be gamed by moving tokens between wallets, so keep perks cosmetic. Not an audit.
